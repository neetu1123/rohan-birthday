# Build a Cinematic Birthday Surprise Website for Rohan Chourasia ❤️

## Project Vision

Create a premium, cinematic, emotionally immersive birthday website for **Rohan Chourasia**, my best friend and the person I dream of spending my future with.

This is a personal birthday gift from me to him. The experience should feel like a romantic short film, a digital love letter, and a beautiful story unfolding through scrolling, animation, music, photographs, and meaningful messages.

The website must be visually stunning, emotionally engaging, interactive, responsive, and completely frontend-only.

**Core feeling:** Midnight romance, cinematic storytelling, soft nostalgia, unspoken feelings, and the hope of a beautiful future together.

Do not create a generic birthday template. Design an original, premium experience with carefully choreographed transitions, beautiful typography, atmospheric backgrounds, and a memorable ending.

---

## 1. Technology Stack

Use the following technologies:

- Next.js with the App Router.
- TypeScript.
- Tailwind CSS.
- Framer Motion for animations.
- Lucide React for icons.
- A lightweight confetti library, such as canvas-confetti.
- React hooks for client-side interactions.

Use client components only where interactivity is required.

No backend, database, API, authentication, payment system, or server-side data storage.

The project must run locally with standard commands:

`npm install`

`npm run dev`

Keep the implementation organized, reusable, and easy to customize.
